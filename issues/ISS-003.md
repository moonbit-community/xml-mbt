## Description
Recursive internal entity expansion detects cycles but has no depth or expanded-size budget. A small document can expand into disproportionately large text and exhaust CPU or memory.

## Design
Apply fixed, package-private depth and expanded-size limits to every transitive entity expansion path, including entities whose replacement text contains markup. Reject over-budget input with a parse error. Avoid adding configuration until a real use case requires it.

## Acceptance Criteria
- [x] Over-depth and over-size entity graphs fail deterministically before large output is constructed.
- [x] Ordinary nested internal entities still parse correctly.
- [x] Text and markup replacement paths enforce the same limits.
