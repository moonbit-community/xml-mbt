# ISS-002: Disable implicit external entity file access

## Metadata
- Type: bug
- Status: open
- Priority: 0
- Labels: parser, security, xxe
- Assignee: unassigned
- Created: 2026-07-13
- Updated: 2026-07-13
- External ref: none

## Description
`Reader::from_file` implicitly resolves `SYSTEM` entities relative to the input file and permits paths to escape that directory. Parsing untrusted XML can therefore disclose arbitrary readable local files.

## Design
Remove automatic filesystem resolution and its stored base path. External entity declarations remain syntactically parseable, but references fail as undefined unless a future explicit resolver API is designed. Do not retain a compatibility switch for the unsafe behavior.

## Acceptance Criteria
- [ ] Parsing a file cannot read a referenced local file through a `SYSTEM` entity.
- [ ] Existing internal entity behavior continues to work.
- [ ] Public documentation no longer promises implicit external entity resolution.
