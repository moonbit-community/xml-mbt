# ISS-004: Enforce XML whitespace and control-character rules

## Description
The parser treats Unicode spacing characters such as non-breaking space as XML whitespace and silently skips invalid control characters in end tags. XML 1.0 permits only space, tab, carriage return, and line feed as grammar whitespace.

## Design
Restrict grammar whitespace to the four XML 1.0 characters and remove control-character skipping from end-tag parsing. Preserve valid character handling in text and references.

## Acceptance Criteria
- [ ] Non-breaking space between a name and attribute is rejected.
- [ ] Invalid control characters in end tags are rejected.
- [ ] All four valid XML whitespace characters remain accepted where grammar permits whitespace.
