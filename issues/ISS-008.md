## Description
`to_libxml_format` is a conformance-test adapter but is declared public, appears in the generated package interface, and is absent from the planned API in `spec.mbt`.

## Design
Make the adapter package-private. Same-package conformance tests can continue using it without exposing a test-specific representation to library users.

## Acceptance Criteria
- [ ] `to_libxml_format` is absent from the generated public interface.
- [ ] Conformance tests still pass.
- [ ] No other code is changed beyond fallout from hiding this symbol.
