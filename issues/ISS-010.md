# ISS-010: Report precise trailing-content spans

## Description
After the root element closes, ordinary trailing content can raise before the offending input is consumed. This produces a zero-width span at the first invalid character, or a span containing only the legal whitespace before it. Other trailing forms report different ranges.

## Design
Skip legal whitespace after the root before recording the error start, consume the complete offending trailing token, and raise an explicit `XmlError::At` for text and character references. Preserve the existing handling of comments, processing instructions, and extra markup, and do not change the public API.

## Acceptance Criteria
- [x] Plain trailing text spans cover the complete text and exclude leading whitespace.
- [x] Trailing entity-reference spans cover the complete reference.
- [x] Trailing extra-element spans cover the complete element markup and exclude leading whitespace.
- [x] Trailing spans retain UTF-16 offsets, and whitespace-only epilogs still reach EOF.
- [x] The full check, interface, and all-target test gates pass.
